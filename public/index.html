缓存机制与计费说明（缓存读、缓存写/存储与双值 TTL 详解）

1. 什么是「缓存读 / 1M」？

多轮对话、Coding Agent 或大文档问答时，每次请求开头往往带着相同的 System Prompt、工具定义和前文历史。如果这些重复前缀命中了服务端已有缓存，命中部分不再按原价「输入」扣费，而是改按缓存读（Cache Read）的超低折扣价计费——常见为标准输入的 0.02×–0.25×（即省 75%–98%）；未命中的新增内容仍按标准输入计费。

2. 什么是「缓存写 / 存储费」？

代表把前缀首次存进缓存的额外代价，分为三种模式：

  • 按写入倍率（multiplier）：首次写入指定 TTL 缓存时一次性加价（如 1.25× / 2.0× / 2.5×），无小时租金，后续命中 1–2 次即回本；
  • 按小时存储（storage_hourly）：显式缓存对象按声明 TTL 持续计内存租金（如 Gemini 3.8 Flash 为 $0.50/1M/h、火山方舟 ¥0.017/1M/h），空闲期也计费；
  • 免写入/存储费（free_auto）：首次按标准输入原价计费，系统后台自动建立缓存。

3. 为什么「缓存时间 (TTL)」经常有两个值？

  • 短档 / 长档两级 TTL（如 Anthropic / Kimi 的 5m / 1h，OpenAI 的 30m / 12h）： 前一个值（5m / 30m）是默认短缓存，写入成本低（1.0×–1.25×），适合连续高频对话与 Agent；后一个值（1h / 12h）是需显式指定的长缓存，写入倍率更高（2.0×–2.5×），适合调用间隔跨分钟、跨小时或全天复用的场景。注：Anthropic、阿里云显式与 Kimi 在有效期内每次命中会自动顺延重置计时。
  • 隐式 / 显式双模式并存（如 Gemini 3.8 Flash 的 隐式自动 / 显式默认 1h 可调，阿里云百炼的 隐式动态 / 显式 5m）： 斜杠前（隐式）无需改代码、免写入和小时存储费，由服务端动态清理，命中率尽力而为；斜杠后（显式）需调用缓存接口主动绑定固定留存时长，换取确定性保留或更低读取折扣（如阿里云显式读 1 折 vs 隐式读 2 折），并对应收取写入倍率或小时存储费。
  • 单一模式：如 Gemini 4 全系、DeepSeek、xAI、MiniMax 仅支持自动隐式缓存，无固定公开过期时间；火山方舟则支持显式自定义 TTL 最长 168h（7 天）并按小时计存储费。

4. 重点说明与 Prompt 排版建议

  • Gemini 4 的 Implicit caching only 是什么意思？：按 Google 官方最新规范，Gemini 4 全系（Carbon / Argon / Neon / Hydrogen）仅支持隐式自动缓存、不提供显式 Context Caching API；因此既不需要手动创建或续期缓存对象，也不会产生每小时存储费——只要请求前缀满足最小长度（通常 ≥ 4,096 tokens）即可由系统自动尽力命中，享约 95% 缓存读折扣。
  • 提高隐式缓存命中率的排版建议：把固定不变的内容（System Prompt、工具/Schema 定义、长篇知识库或代码上下文）放在请求最前方，把每轮变化的用户提问、实时状态放在最后方；不要在固定前缀开头插入时间戳、随机 Request ID 或动态变量，尽量避免无谓调整工具列表与前缀顺序，并保持相对紧凑的调用间隔。

估算方法说明（四类套餐分别如何计算？）
  • 官方公式精算（智谱 GLM Coding Plan）：依据公开的 GLM-5.4 积分公式 消耗积分 = (未命中输入×4.6 + 缓存命中×1.1 + 输出×16) / 10000，将周积分乘以 4.33 折算月积分，再按你设置的输入/缓存/输出比例反推可运行的总 Token；非高峰 5 折时段再乘 2×。
  • 固定额度换算（GitHub Copilot）：按官方公开月额度（Pro $15 / Pro+ $70 / Max $200）除以对应参考模型的混合单价，得出确定额度内可支撑的 Token 总量（未计入其无限内联代码补全）。
  • 按次折算（阿里云百炼 / 火山方舟 Coding Plan）：Agent 每次提问常触发 10–30 次底层模型调用。以「月度调用次数上限 × 单次平均 Token 滑块」计算理论上限，并以 35% 实际月均利用率给出务实估算区间。
  • 动态池估算（ChatGPT / Claude / Google AI / Cursor / Kimi / MiniMax）：此类套餐官方未公布绝对月 Token 上限，表格依据附赠 API Credits 与社区/官方公开的档位倍数推算等效 API 价值区间，再按当前参数换算为月度 Token 参考区间。
